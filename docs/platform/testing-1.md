# Project Context: Remote Biometric Attendance Management System for HRMS

## Background

I am building an HRMS application.

Currently, our attendance module works as follows:

* Every client has one or more biometric machines (mostly ESSL/ZKTeco).
* Multiple biometric machines may exist in one company.
* A Python application is installed on the client's Windows PC.
* That Python application connects to biometric machines over the local LAN.
* It fetches attendance logs from the machines.
* It uploads those logs to our HRMS cloud database through APIs.
