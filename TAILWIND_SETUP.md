# Tailwind CSS Setup for Docusaurus

To use Tailwind CSS in this Docusaurus project, you need to install it first:

## Installation

```bash
npm install -D tailwindcss postcss autoprefixer
```

## Configuration

The following files have been created:
- `tailwind.config.js` - Tailwind configuration
- `postcss.config.js` - PostCSS configuration

## Usage

After installation, the Tailwind utility classes will work in:
- React components
- CSS files (using @apply directive)
- Markdown files

The sidebar component already uses Tailwind classes and will work once Tailwind is installed.
